# Светлый интерфейс «Не Усложняй»

Обновление включает светлый фон, фирменный оранжевый, графитовую навигацию, адаптивные карточки и нижнее меню на телефоне. Страница входа использует ту же стилистику; обработчики Auth, установки пароля и восстановления ссылки не менялись.

Дашборд использует только доступные по RLS данные:
- активные задачи, просрочки, задачи на проверке и завершённые за последние 7 дней;
- блок внимания с запросами переноса и подтверждениями;
- ближайшие платежи из задач и регулярных правил (без вымышленных сумм);
- задачи на сегодня / 7 дней с фильтром сотрудника;
- загрузка сотрудников по текущим активным задачам.

Показатели открывают соответствующий список. Поиск работает по названию, описанию и ожидаемому результату. Основной список задач загружается страницами, чтобы стандартный лимит Supabase не обрезал показатели после накопления истории.

## Чек-листы

Для сохраняемых отметок применить **один раз** в Supabase SQL Editor:
`supabase/migrations/20261001020000_task_checklists.sql`.

До применения миграции дизайн работает, а пункты чек-листов доступны только для чтения. После миграции достаточно обновить страницу.

Пункты берутся из строк описания, начинающихся с `•`, `-`, `–` или `*` и пробела. Такие строки уже есть у ежедневных задач управляющего. Исполнитель и руководитель с правом управления задачей могут отмечать пункты. Завершённая задача доступна только для чтения. Отметки записываются в историю; права проверяются в PostgreSQL, произвольная запись в таблицу запрещена. Если описание изменилось, сервер проверяет актуальный текст пункта. Изменение позиции или текста пункта сбрасывает его соответствие старой отметке.

## Проверки

- `npm run build`.
- `npx eslint app/dashboard/page.tsx app/dashboard/Overview.tsx app/dashboard/TaskChecklist.tsx app/dashboard/Drawer.tsx app/dashboard/ui.tsx`.
- `NU_PGLITE_PATH=/absolute/path/to/@electric-sql/pglite/dist/index.js node scripts/test-recurring.cjs`: календарь, RLS, сохранение отметок, запрет чужих/завершённых задач и прямых записей.
- `NU_START_SERVER=1 node scripts/test-dashboard-ui.cjs`: браузерные сценарии с локальными фикстурами. Нужны Playwright и установленный Chromium. Тест сам запускает production-сборку на 127.0.0.1:3100 и перехватывает все обращения к тестовому Supabase. Он рассчитан на сборку без настоящих NEXT_PUBLIC_SUPABASE_* переменных. Никогда не использует реальные учётные записи.

Browser smoke покрывает desktop и mobile, показатели, поиск, фильтры, открытие/закрытие карточки, сохранение чек-листа, форму создания, календарь и команду; проверяет отсутствие горизонтального переполнения и JS-ошибок.
