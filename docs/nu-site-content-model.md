# Контент-модель NU public site

## site_locations
Карточки заведений: город, название, адрес, телефон, описание, фото, ссылки 2ГИС/Яндекс, рейтинги, порядок, featured/published.

## site_articles
Материалы журнала: slug, заголовок, excerpt, body, категория, обложка, связь с конкретным заведением, featured/published, дата публикации.

## site_franchise_leads
Заявки франшизы: имя, телефон, город, бюджет, источник, дата.

## Редакционные роли
- owner: полный доступ.
- manager: управление заведениями и материалами.
- smm: создание/редактирование/публикация материалов журнала.
