# NU OS Autopilot

Этот файл — рабочая очередь для автономного развития NU OS.

## Правила

1. Не ждать подтверждения пользователя для безопасных, обратимых изменений в отдельной ветке.
2. Перед merge проверять сборку и затронутые сценарии.
3. Не удалять данные, пользователей, задачи и production-секреты без явной необходимости и отдельного подтверждения.
4. Любые изменения схемы Supabase оформлять миграцией и проверять права/RLS.
5. Если шаг упирается только в отсутствующий секрет, доступ или бизнес-решение, остановить именно этот шаг и сообщить точный блокер.
6. После завершения пункта отмечать его выполненным и брать следующий безопасный пункт.
7. Пользователю сообщать в первую очередь о готовых результатах и реальных блокерах, а не о каждом техническом движении.
