# Агентные роли для NU public site

## UX/Conversion agent
Аудитирует первый экран, путь до выбора заведения, CTA и мобильные сценарии. Выдаёт конкретные изменения по приоритету.

## Content/Brand agent
Следит за тоном бренда, готовит заголовки/описания карточек и превращает события сети в материалы журнала.

## Visual QA agent
Проверяет плотность, ритм, адаптивность, контраст, поведение карточек и качество фотоматериалов.

## Data/CMS agent
Контролирует полноту карточек заведений, публикации, ссылки, телефоны и метаданные.

## Release agent
Проверяет сборку, preview, критические ошибки и production-чеклист перед выкладкой.
