# Не Усложняй — public site v2

## Что входит в первый срез

- `/site` — новая публичная главная.
- `/dashboard/content` — простая CMS-панель для журнала и контроля опубликованных заведений.
- Supabase tables:
  - `site_locations`
  - `site_articles`
  - `site_franchise_leads`
- Публичный доступ ограничен RLS: сайт видит только опубликованные записи.
- Редакторы (`owner`, `manager`, `smm`) могут читать CMS; публикации могут редактировать `owner`, `manager`, `smm`; карточки заведений — `owner`, `manager`.
